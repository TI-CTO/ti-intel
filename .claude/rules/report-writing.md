# Report Writing Rules

모든 리포트(weekly-monitor, WTIS standard/full)에 공통 적용되는 작성 규칙.

## 약어 (Abbreviations)

- 약어를 최초 사용할 때 반드시 전체 용어를 함께 표기한다: `Full Term (ABBR)`
- 이후 같은 문서 내에서는 약어만 사용 가능
- Executive Summary에서 사용한 약어라도 본문 첫 등장 시 다시 풀어 쓴다 (Executive Summary는 독립 섹션)
- 널리 알려진 약어(AI, API, SDK, URL 등)는 예외

## 인용 앵커 링크

본문에서 레퍼런스를 인용할 때 클릭 가능한 앵커 링크를 사용한다:

**본문:**
```markdown
PQC 표준은 2025년 확정되었다 [[G-01]](#ref-g-01).
```

**References 테이블:**
```markdown
| <a id="ref-g-01"></a>G-01 | postquantum.com | https://... | 2025-03 | high |
```

이 형식은 Obsidian, GitHub, PDF 렌더러(design-system)에서 모두 클릭 → 점프 동작한다.

## References ID 규칙

- **순차 번호만 사용**: `G-01`, `P-02`, `E-03` 형식. 접미사(`-S`, `-C`, `-v2` 등) 금지.
- **선행 리서치 합칠 때**: 충돌하는 ID는 순차 재번호 매기기로 해소.
- **유형별 01부터 시작**: G(글로벌/뉴스), P(논문), E(기업 발언), N(동향), T(특허), I(내부).
- **이유**: 접미사 ID는 마크다운 파서 호환성 문제, PDF 뱃지 렌더링 오류, 검증 체계 불일치를 유발.

## References 테이블

- 모든 출처 유형(G/N/E/P/T)을 **하나의 테이블**에 통합. 유형별 분리 금지.
- References는 **전수 보존** — 요약·축소·삭제하지 않는다.
- URL: `[링크](url)` 마크다운 링크.
- 복수 출처 인용 시 `, `로 구분: `[[G-01]](#ref-g-01), [[G-02]](#ref-g-02)`

## 저자 표기

- 저자 3인 이상: "First Author et al." 형식
- 논문 인용: "제목 (저자, 연도)" 형식

## 수치 출처 표기

- 모든 재무·시장 수치에 출처를 명시하거나 `[추정]` 태그를 붙인다.
- 수치 테이블(연도별 통계, TAM/SAM/SOM 등)은 원본 그대로 보존. 축소·생략 금지.

## PDF 렌더링 호환

- **코드 블록 안에 체크리스트 금지**: ` ``` ` 안의 `- [ ]`는 raw 텍스트로 렌더링됨. 일반 마크다운 리스트로 작성.
- **테이블 셀 간결하게**: 5열+ 테이블에서 한 셀에 장문 금지. 핵심 키워드만 넣고 상세는 본문에 서술.
