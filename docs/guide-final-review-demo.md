## 데모 시나리오 (15분)

### 1. 플랫폼 소개 (2분)

**보여줄 것**: 터미널에서 `claude` 실행 → 한눈에 보기 다이어그램

**말할 것**:
- 3계층 구조: 스킬(명령어) → 에이전트(자동) → MCP(데이터)
- 자연어로 말하면 됨, 슬래시 명령어는 편의 기능
- 현재 데이터: intel-store 724건, startup-db 807개사

### 2. 데이터 검색 (3분)

**시연**:
```
"PQC 관련 최신 동향 알려줘"
```
→ `search_intel(query="PQC", mode="hybrid")` 자동 호출 → 결과 확인

```
"이 중에서 논문만 보여줘"
```
→ `search_intel(query="PQC", types=["paper"])` 재검색

**포인트**: 수집된 데이터에서 즉시 검색. 키워드 + AI 시맨틱 하이브리드 검색.

### 3. 데이터 수집 (3분)

**시연**:
```
"edge AI security 관련 최신 뉴스 수집해줘"
```
→ `collect_news(topic="ondevice-slm", query="edge AI security")` 실행
→ 수집 건수 + 저장 결과 확인

**포인트**:
- 논문(Semantic Scholar/arXiv) + 특허(Google Patents) + 뉴스(Tavily/GDELT/Naver) 6개 소스
- 관련성 필터링(코사인 0.8)으로 노이즈 자동 제거
- 한번 수집하면 이후 검색에서 바로 활용

### 4. 주간 모니터링 리포트 (3분)

**시연**: 기존 산출물 보여주기 (라이브 실행은 시간 관계상 생략)

```
"지난주 secure-ai 주간 리포트 보여줘"
```
→ `outputs/reports/weekly/2026-03-18_weekly-secure-ai.md` 열기

**보여줄 것**:
1. Executive Summary (🔴🟡🟢 신호등)
2. Deep 리서치 결과 (변화 감지된 L3만 심층 분석)
3. PDF 산출물 열어서 보여주기

**포인트**:
- 2단계: 전체 L3 빠른 스캔 → 변화 감지된 것만 심층 분석
- 월(Agentic AI) / 화(Voice AI) / 수(Secure AI) 자동 실행 (launchd 등록 완료)
- 경쟁사(SKT/KT) 섹션 포함

### 5. WTIS 판정 + 포트폴리오 (4분)

**시연**: 기존 산출물 보여주기

```
"Secure AI 포트폴리오 보여줘"
```
→ `outputs/reports/secure-ai/secure-ai-portfolio.md` 열기

**보여줄 것**:

**포인트**:

## FAQ (예상 질문)

### 사용법

**Q: 슬래시 명령어를 외워야 하나요?**
A: 아닙니다. 자연어로 말하면 됩니다. "이 기술 투자할 만한지 판단해줘"라고 하면 `/wtis`가 실행됩니다. 슬래시 명령어는 정확한 제어가 필요할 때만 사용합니다.

**Q: VSCode에서 쓸 수 있나요?**
A: MCP 도구(데이터 수집/검색)는 터미널 Claude Code에서만 가능합니다. VSCode Claude 확장은 일반 코딩 대화만 가능합니다.

**Q: 처음 쓸 때 뭐부터 하면 되나요?**
A: `docs/guide-team-quickstart.md`의 §4 역할별 워크플로우를 참고하세요. 전략기획/사업기획/개발 역할별 핵심 흐름이 정리되어 있습니다.

### 데이터

**Q: 새 주제를 검색했는데 결과가 없어요**
A: 먼저 수집이 필요합니다. "XXX 관련 논문/뉴스 수집해줘"라고 하면 됩니다. 수집 후 검색 가능합니다.

**Q: 데이터는 얼마나 있나요?**
A: intel-store에 724건 (뉴스 83%, 논문 14%, 특허 3%). 25개 L3 기술 + 경쟁사 2개 = 27개 토픽. startup-db에 807개 스타트업, 689건 펀딩.

**Q: 데이터가 실시간으로 업데이트되나요?**
A: 아닙니다. 주간 모니터링이 월/화/수 09:00에 자동 실행되고, 수동으로 `collect_all`을 호출할 수도 있습니다.

**Q: 한국어 검색이 되나요?**
A: 됩니다. `mode="hybrid"`를 사용하면 AI 시맨틱 검색이 한국어 조사 분리 문제를 보완합니다.

### 비용/쿼터

**Q: 비용이 드나요?**
A: Anthropic API 사용량 기반 과금 외에는 대부분 무료입니다. SerpAPI(특허, 월 250회)와 Tavily(뉴스, 월 1,000회)는 무료 티어 내에서 운영 중입니다.

**Q: API 쿼터가 다 쓰이면?**
A: 특허 수집만 중단됩니다. 뉴스/논문은 무료 소스로 자동 폴백합니다. Anthropic API 초과 시 전체 중단 — 즉시 관리자에게 보고하세요.

### WTIS 판정

**Q: 200점 점수는 어떻게 매기나요?**
A: 5개 차원(기술 성숙도, 시장 적합성, 경쟁우위, 실행 가능성, 전략 정합성) × 40점씩. opus 모델이 정량 채점하고, validator가 독립 검증합니다.

**Q: 판정 결과를 누가 최종 승인하나요?**
A: WTIS는 의사결정 "근거"를 제공합니다. Go/No-Go는 참고 판정이며, 최종 의사결정은 담당자가 합니다.

**Q: 이전 평가를 업데이트할 수 있나요?**
A: 같은 L2 기술을 다시 `/wtis standard`로 실행하면 됩니다. 포트폴리오에 최신 평가가 자동 반영됩니다.

### 운영

**Q: 자동화는 어떻게 되나요?**
A: 월/화/수 09:00에 launchd가 각 도메인 주간 모니터링을 자동 실행합니다. PC가 켜져 있으면 자동, 꺼져 있으면 수동 실행 필요합니다.

**Q: 장애가 나면 어떻게 하나요?**
A: `docs/guide-team-quickstart.md` §10 장애 대응을 참고하세요. MCP 서버 상태 확인, API 쿼터 관리, 수집 에러 대응 절차가 정리되어 있습니다.

**Q: 새 도메인이나 기술을 추가하려면?**
A: intel-store에 토픽 등록 → watch_topics 추가 → 데이터 수집 순서입니다. 분류체계 변경은 `tech-taxonomy.md` 수정이 필요합니다.
