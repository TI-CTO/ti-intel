# 월간 종합 리포트 설계

> 최종 설계: 2026-04-17 | 구현: `scripts/auto-monitor/run-friday.sh` Task 7

## 개요

월간 종합 리포트는 4주간 누적된 주간 리포트, 포트폴리오 리뷰, 딜 파이프라인 등을 **CTO 보고용 단일 브리핑**으로 통합하는 산출물이다. 새로운 분석을 수행하는 것이 아니라, 기존 자동화 산출물을 읽고 종합 요약한다.

## 실행 조건

- **시점**: 매월 마지막 금요일 (다음 금요일이 다음 달이면 트리거)
- **자동화**: `run-friday.sh` Task 7 (claude -p 호출)
- **max_turns**: 40
- **파일명**: `outputs/reports/{DATE}_monthly-synthesis.md` + PDF

## 입력 소스

| # | 소스 | 빈도 | 자동 생성 |
|---|------|------|----------|
| 1 | 주간 종합 (weekly-summary) | 매주 금 | Task 1 |
| 2 | 도메인별 주간 리포트 (weekly-*.md) | 매주 월~화 | run-domain.sh |
| 3 | 데이터 건강 체크 | 매주 금 | Task 2 |
| 4 | 월간 포트폴리오 리뷰 | 매월 첫째 금 | Task 3 |
| 5 | 월간 딜 파이프라인 리뷰 | 매월 첫째 금 | Task 4 |
| 6 | 도메인별 portfolio.md | WTIS 실행 시 | 수동/자동 혼합 |
| 7 | intel-store 통계 | 실시간 | get_intel_stats MCP |

## 리포트 구성 (7개 섹션)

### 1. Executive Summary (반쪽)
이번 달 핵심 3~5가지. 4주 중 가장 임팩트 큰 시그널을 선별.

### 2. 도메인별 월간 추이 (1쪽)
4주 신호 뱃지 집계 테이블 + 트렌드 한줄 코멘트.

| 도메인 | W1 | W2 | W3 | W4 | 트렌드 |
|--------|----|----|----|----|--------|
| Agentic AI | ... | ... | ... | ... | 한줄 |

### 3. 포트폴리오 변동 (반쪽)
- 점수 상승/하락 L2 목록
- Go 전환 후보 진전 상황
- 재평가 결과 (해당 월 WTIS 실행 건)
- 소스: 월간 포트폴리오 리뷰(Task 3) + portfolio.md

### 4. 경쟁사 포지셔닝 (반쪽)
- SKT/KT 월간 핵심 액션
- 우리 차별화 기회
- 소스: 주간 종합 경쟁사 섹션 4주 통합

### 5. 딜 파이프라인 (반쪽)
- 신규 진입 / 단계 변경 / 탈락
- 소스: 월간 딜 리뷰(Task 4)
- 딜 리뷰 없으면 생략

### 6. 수집 통계 (반쪽)
- 총 건수, 월간 신규 건수
- 유형별 분포 (news/paper/patent/community)
- 편중 영역 경고
- 소스: intel-store get_intel_stats

### 7. 다음 달 액션 (반쪽)
- WTIS 재평가 대상
- 보충 수집 영역
- 운영 개선 사항

## 자동화 vs 수동 구분

| 영역 | 자동 | 수동 |
|------|------|------|
| 리포트 생성 | ✓ Task 7 | — |
| PDF 렌더링 | ✓ design-system MCP | — |
| 입력 데이터 수집 | ✓ Task 1~6에서 이미 생성 | — |
| CTO 코멘트 추가 | — | 생성 후 수동 편집 |
| WTIS 실제 재평가 | — | `/wtis standard` 수동 호출 |
| Obsidian 동기화 | ✓ obsidian-bridge (향후) | 현재 수동 복사 |

## 금요일 자동화 전체 태스크 맵

```
run-friday.sh (매주 금 09:00)
├── Task 1: 주간 종합 리포트          ← 매주
├── Task 2: 데이터 건강 체크          ← 매주
├── Task 3: 월간 포트폴리오 리뷰      ← 매월 첫째 금
├── Task 4: 딜 파이프라인 리뷰        ← 매월 첫째 금
├── Task 5: 분기 WTIS 재평가 목록     ← 분기 첫째 금
├── Task 6: 분기 경쟁사 전략 종합     ← 분기 첫째 금
└── Task 7: 월간 종합 리포트          ← 매월 마지막 금 ★ NEW
```
