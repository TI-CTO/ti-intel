# WTIS 선정검증: 의도 파악 기술 (Adaptive RAG)

## Executive Summary

> **Conditional Go — 131/200점, 신뢰도 Medium.** Adaptive RAG(CRAG, Query Routing, Self-RAG)는 CAGR 38.4%의 고성장 시장(TAM $9.86B, 2030) [G-01]에서 핵심 기술(TRL 7~8)이 엔터프라이즈 배포 가능 수준에 도달했으며, AI 기본법 투명성 의무가 RAG 채택을 가속하는 규제 드라이버로 작용한다 [G-12]. 그러나 SKT AICC(2024.10 가동) [E-01]과 KT Agentic AICC(MWC 2026 공개) [E-02]가 선점한 후발 진입 상황이며, 자사 내부 역량 데이터가 전무하여 실행가능성과 경쟁우위 평가에 한계가 있다. **Borrow + Build 하이브리드 전략** — 인프라는 클라우드 파트너십으로 조달하고, 한국어 Telco 도메인 특화 CRAG 평가기·청킹 파이프라인을 자체 개발하는 것을 권고한다.

### 기술별 상세 평가

| 기술 패턴 | TRL | 파괴적 잠재력 | 사분면 | 함의 |
|-----------|-----|-------------|--------|------|
| 기본 RAG | 9 | Low | 유지 | 수천 개 프로덕션 배포 완료, 차별화 불가 — 기반 인프라 |
| **CRAG** | 7~8 | **High** | **베팅** | 검색 품질 자기 교정, 엔터프라이즈 배포 표준 정착 [G-04], Higress-RAG 90%+ 리콜 [P-05] |
| **Adaptive Routing** | 7~8 | **High** | **베팅** | 30~40% 비용 절감 확인 [G-04], LangGraph/Databricks 상용화 |
| **Multi-hop Agentic RAG** | 7~8 | High | 베팅 | A-RAG HotpotQA 94.5% [P-01], 57%+ 프로덕션 채택 |
| Self-RAG | 6~7 | Medium | Watch | 학술 연구 충분하나 프로덕션 복잡도 높음 [G-20] |
| 멀티턴 Adaptive RAG | 6~7 | High | Watch | EMNLP 2025 산업 트랙 발표 [P-03], 고객센터 파일럿 단계 |
| Voice x RAG | 5~6 | High | Watch | Salesforce 연구 단계, 캐시 히트 316배 속도 [P-02], 프로덕션 미검증 |

**판단**: CRAG + Adaptive Routing이 즉시 배포 가능한 "베팅" 영역이며, Self-RAG와 멀티턴 Adaptive RAG는 중기(2027) 대비 Watch 대상. Voice x RAG는 장기(2028+) 기회.

### 의사결정 로직 적용

```
차별화 중요도(7) < 8 → BUILD 단독 불충분
시장 긴급도(8) ≥ 8 → BUY 고려
기술 격차(1~2년) < 2년 → BORROW 적합
```

**결론: Borrow + Build 하이브리드**

- **Borrow** (파트너십): 벡터DB(Pinecone/Weaviate), 오케스트레이션(LangGraph), 클라우드 인프라(AWS Bedrock 또는 Google Vertex AI), 평가 프레임워크(Databricks Agent Evaluation)
- **Build** (자체 개발): 한국어 Telco 도메인 특화 청킹·임베딩 파이프라인, CRAG 평가기(통신 약관·요금제 도메인), 멀티턴 대화 상태 관리기

**Buy 제외 이유**: 현 시점에서 Telco RAG 전문 기업 인수 대상이 부재하며, Kore.ai 등 글로벌 솔루션은 한국어·통신 도메인 특화가 약점 [G-08]. 라이선싱보다 파트너십 + 자체 핵심 모듈 개발이 비용 효율적.
